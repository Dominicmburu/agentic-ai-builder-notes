Your first n8n AI agent

Meet n8n, build a chat agent with no code, and run it live.

About 40 minutes to read Core Download the slides

The big idea

n8n lets you build automations by connecting boxes on a canvas instead of writing code. Each box does one job. This week you turn what you learned about AI into working workflows.

By the end you can:

  • Find your way around n8n cloud and name its parts: node, connection, workflow, execution and template.
  • Build and run a chat agent that has an AI model connected.
  • Run a workflow by hand for testing, then switch it on for real use.

The five words you need

Everyday comparison: a factory assembly line A workflow is like an assembly line. Each station (node) does one job. Conveyor belts (connections) carry the item to the next station. Each time the line runs, that is one execution.
WordPlain meaningOn the assembly line
NodeOne step. It is either a trigger that starts the workflow, or an action that does something.One station
ConnectionThe line between two nodes. It passes data along.The conveyor belt
WorkflowA set of connected nodes that does a whole job.The entire line
ExecutionOne run of a workflow, saved so you can look back at it.One batch going down the line
TemplateA ready-made workflow you can copy and adapt.A recipe card

A trigger node answers the question “what starts this?” (a chat message, a schedule, an incoming web request). Action nodes answer “what should happen next?”

Getting set up

  1. Create an account on n8n.io and start the free trial of n8n cloud. After the trial it is a monthly subscription.
  2. Click Create workflow. You will see an empty canvas. Give the workflow a name such as “My first agent”.
  3. Get an AI key. OpenAI needs a minimum balance. OpenRouter is a free-tier alternative, and it uses the same key idea you met in Lesson 1.
Keep your key private In n8n you paste keys into a credential, a safe box that n8n stores for you. Never paste a key into a prompt, a spreadsheet or a message.

Build the agent

This is the whole workflow. Three boxes:

  1. Click the + on the canvas and add a chat trigger, often named On chat message.
  2. Add an AI Agent node and connect it to the trigger.
  3. On the AI Agent node, find the Chat Model slot at the bottom and click its +. Choose an OpenAI or OpenRouter chat model.
  4. Create a credential with your key when asked, then pick a model name.
  5. Open the AI Agent's options and add a System Message. This is the system prompt from Lesson 3.

Here is a system message to try. You will replace the text in the middle each time.

System messageYou are a helpful assistant. Answer questions using ONLY the text below. If the answer is not in the text, say: "I can't find that in the text." Keep answers to two sentences. TEXT: (paste a short article, a menu, or a set of opening hours here)

Test it

  1. Click Open chat (or the chat button on the canvas) and ask a question about your text.
  2. Ask something that is not in the text. A good agent should say it cannot find it.
  3. Click Executions and open the latest run. Click each node to see what went in and what came out.

Reading an execution is the most useful habit in n8n. When something goes wrong, the answer is nearly always visible there.

Manual runs and live runs

Manual execution

For testing. You press the button and watch it work on the canvas.

Active execution

For real use. After you turn the workflow on, it runs by itself whenever its trigger fires.

The button is called Active in some versions and Publish in newer ones. It does the same job. Always test by hand before switching on.

What does it cost?

  • n8n cloud: a free trial, then a monthly subscription.
  • OpenAI: needs a minimum balance in your account before the key works.
  • OpenRouter: has free models with limits, which suits learning.

Your exercise

Build a chat agent that answers questions about a short text you paste into its prompt. Run it, then open the execution view and read each step.

If something goes wrong

What you seeWhat it usually means
The agent node shows an error about a missing modelNo chat model is attached. Click the Chat Model + on the agent.
Credential errors or 401The key is wrong, or the provider has no balance. Re-create the credential.
The chat window shows nothingSave the workflow, then open the chat again.
It answers things that are not in the textMake the rule stronger and add an example of the refusal.

Glossary

n8n
A tool for building automations by connecting boxes (nodes) on a canvas.
Node
One step in a workflow. Either a trigger or an action.
Trigger
A node that starts a workflow, such as a chat message or a schedule.
Action
A node that does something after the trigger, such as call an AI or send an email.
Connection
The line between two nodes that passes data along.
Workflow
A set of connected nodes that does a whole job.
Execution
One run of a workflow, saved so you can inspect it.
Template
A ready-made workflow you can copy and change.
Credential
A safe place inside n8n where a key or login is stored.
Active (or Publish)
Switching a workflow on so it runs by itself in real use.

Recap and what comes next

  1. n8n builds automations from connected boxes: nodes joined by connections make a workflow.
  2. A chat agent needs three things: a trigger, an AI Agent node and a chat model.
  3. Test by hand, read the execution, and only then switch the workflow on.
