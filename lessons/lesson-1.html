Meet the AI that reads and writes

An introduction to LLMs and APIs, with no technical background needed.

About 45 minutes to read No coding required Download the slides

The big idea

An AI like ChatGPT works by guessing what text should come next. A program can talk to it by sending a neat written order, called an API request.

That is the whole lesson in two sentences. The rest of this page explains each part slowly, using everyday examples.

By the end you can:

  • Explain what an AI language model does, in your own words.
  • Tell apart three names people mix up: LLM, GPT and ChatGPT.
  • Send a real request to an AI and read the answer.

You already use a tiny version of this

Open any messaging app on your phone and type Good morning, how are. Your keyboard suggests the next word: you. It has seen millions of messages, so it knows what usually comes next.

Everyday comparison An LLM is like your phone's word suggestions, but supercharged. Instead of one word, it can continue a whole paragraph.
Try it: what would the AI guess next?

The percentages are made-up examples to show the idea. Real models weigh thousands of possible words in the same way.

What is an LLM?

LLM stands for Large Language Model. In one sentence:

A program that has read a huge amount of text and learned to guess what comes next.

Large

It learned from billions of words: books, websites, articles and more.

Language

Its world is words. It reads, writes and translates.

Model

A “model” is a pattern the computer has learned. It is not a person and not a brain.

Try saying the definition in your own words. A good version: “It is a program trained on lots of text to predict what text comes next, and by repeating that it can write sentences, code and answers.”

How it writes a whole answer

The AI does not plan a full answer first. It works one small piece at a time:

  1. Read everything written so far.
  2. Guess the most likely next piece of text.
  3. Add that piece, then go back to step 1.

It repeats this very fast until the answer is complete. Try the same game yourself: The sun rises in the ... You said “east” without thinking. The AI does that, millions of times.

A small word you will meet next lesson The “pieces” are called tokens. A token is a chunk of text, often a whole word or part of one. You do not need to know more today.

It guesses, it does not look up

This is the most important thing to understand. The AI produces text that sounds right. It does not open a book or check a website to confirm.

It is great at

Writing and rewriting, summarising long text, translating, explaining ideas simply.

Be careful with

Exact facts, numbers, dates, names, quotes and references. It can get them wrong and still sound sure.

Real-life example Ask an AI for a book that proves a certain point. It may give a title and author that sound perfect but do not exist. When an AI makes something up like this, people call it a hallucination.

Simple rule for this whole course: use the AI to help, then check anything important yourself.

LLM, GPT and ChatGPT: three names, one family

People use these words as if they mean the same thing. They do not. Think about cars:

NameWhat it isCar comparison
LLMThe whole category of AI language modelsThe word “car”
GPTOne family of LLMs, made by a company called OpenAIOne car model, like a Corolla
ChatGPTAn app with a chat window, built on GPT modelsThe car you actually drive, with seats and a dashboard

The same pattern is everywhere. Claude and Gemini are models too, and each has an app you chat with. So when someone says “I asked GPT”, they usually mean they used the ChatGPT app.

Two kinds of models

Chat model

The quick-answer friend. Replies straight away. Cheaper and faster.

Good for: emails, summaries, rewriting, simple questions.

Reasoning model

The friend who works it out on paper first. Slower and costs more.

Good for: puzzles, multi-step maths, planning.

TipStart with a chat model. Switch to a reasoning model only if the answers are not good enough.

What is an API?

So far you have used AI by typing into a chat window. But a program cannot type into a window. It needs a way to send questions to the AI and receive answers. That way is called an API.

Everyday comparison: the restaurant You sit at a table. You do not walk into the kitchen. A waiter takes your order to the kitchen and brings the food back. An API is the waiter between your program (you) and the AI (the kitchen).
In the restaurantIn the AI world
YouYour app or program
The waiterThe API
The kitchenThe AI model
Your orderThe request
The food that comes backThe response (the answer)

What happens when your program orders:

  1. Your program writes the order as a tidy form (JSON, explained below).
  2. It sends the order to the right address, together with your ID card (your key).
  3. The service checks your ID card.
  4. The AI writes the answer, piece by piece.
  5. The answer comes back as another tidy form, and your program reads it.

Every order has four parts

PartPlain meaningRestaurant comparison
EndpointThe web address you send the order toThe restaurant's street address
MethodThe kind of action. GET means “give me something”. POST means “here is an order”. Talking to an AI uses POST.Asking the menu vs placing an order
API keyA secret password that proves it is you and tells them who to billYour ID or membership card
BodyThe order itself, written as JSONThe order slip
Protect your key Treat your API key like a bank PIN. Never share it, never post it on social media, and never put it in a file you upload to GitHub. Anyone with your key can spend your account's money.

What is JSON?

JSON is just a tidy way of writing a form so that a computer can read it. Here is a paper form, and the same form in JSON:

Paper form

Name: Wanjiru
Drink: tea
Sugar: yes

JSON

{
  "name": "Wanjiru",
  "drink": "tea",
  "sugar": true
}

Four simple rules:

  • Labels and words go in double quotes: "name".
  • Curly braces { } wrap the whole form.
  • true and false are written in lowercase, with no quotes.
  • Put a comma between items, but no comma after the last one.

Most beginner problems with APIs are tiny typing mistakes in JSON, so let's practise.

Fix the JSON

Pick a broken example, fix it in the box, then press Check. The computer will tell you if it can read it.

A real request and answer

Now put it together. This is what a program sends to an AI, and what comes back. You do not need to memorise it. Just find where the question goes and where the answer arrives.

What you send
{
  "model": "some-ai-model",
  "messages": [
    {
      "role": "user",
      "content": "Explain what an API is to a 12-year-old."
    }
  ]
}
What comes back (shortened)
{
  "choices": [
    {
      "message": {
        "content": "An API is like a waiter for apps..."
      }
    }
  ],
  "usage": {
    "total_tokens": 50
  }
}
  • Your question goes in "content" under "user".
  • The answer comes back in "content" inside "choices".
  • "usage" counts how much text was used. This is what decides the price.
For the curious: send this request yourself (optional)

You will need a free account at openrouter.ai and an API key. OpenRouter is like a market stall with many different AIs, all reachable with one account and one key. Copy a model name from its models page and replace MODEL_ID.

Option 1, no code: use the chat page on the OpenRouter website. Pick a model, type your question, and read the answer. This is perfectly fine for the exercise below.

Option 2, a terminal command. Pick the one for your computer, and replace YOUR_KEY_HERE and MODEL_ID first. Each computer types these differently, so a command copied from the wrong box will fail.

Windows, PowerShell (the blue window). Paste all of it, then press Enter:

$body = @{
  model = "MODEL_ID"
  messages = @(@{ role = "user"; content = "Explain what an API is to a 12-year-old in three sentences." })
} | ConvertTo-Json -Depth 5

Invoke-RestMethod -Uri "https://openrouter.ai/api/v1/chat/completions" `
  -Method Post `
  -Headers @{ Authorization = "Bearer YOUR_KEY_HERE" } `
  -ContentType "application/json" `
  -Body $body | ConvertTo-Json -Depth 10

Windows, Command Prompt (cmd). This must be one single line:

curl.exe https://openrouter.ai/api/v1/chat/completions -H "Authorization: Bearer YOUR_KEY_HERE" -H "Content-Type: application/json" -d "{\"model\": \"MODEL_ID\", \"messages\": [{\"role\": \"user\", \"content\": \"Explain what an API is to a 12-year-old in three sentences.\"}]}"

Mac or Linux, Terminal:

curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "messages": [
      {"role": "user", "content": "Explain what an API is to a 12-year-old in three sentences."}
    ]
  }'

Why three versions? The reply is the same JSON in all of them. Only the typing rules differ: PowerShell and cmd treat quote marks and line breaks differently from Mac and Linux. If a command gives a strange error, you almost always pasted the wrong version for your window.

Option 3, a short Python script that asks two models the same question and times them. First install the helper once with pip install requests. Save your key in an environment variable called OPENROUTER_API_KEY instead of typing it into the file. Set it in the same window you will run the script from:

# Windows PowerShell
$env:OPENROUTER_API_KEY = "YOUR_KEY_HERE"

# Windows Command Prompt (cmd)
set OPENROUTER_API_KEY=YOUR_KEY_HERE

# Mac or Linux
export OPENROUTER_API_KEY="YOUR_KEY_HERE"

These last only until you close the window. Then save the script below as ask.py and run it with python ask.py (on Windows, py ask.py also works).

import os
import time
import requests

API_KEY = os.environ["OPENROUTER_API_KEY"]
URL = "https://openrouter.ai/api/v1/chat/completions"
QUESTION = "Explain what an API is to a 12-year-old in three sentences."

# Copy two model names from openrouter.ai/models
MODELS = ["MODEL_ID_1", "MODEL_ID_2"]

for model in MODELS:
    start = time.time()
    resp = requests.post(
        URL,
        headers={"Authorization": f"Bearer {API_KEY}",
                 "Content-Type": "application/json"},
        json={"model": model,
              "messages": [{"role": "user", "content": QUESTION}]},
        timeout=60,
    )
    seconds = time.time() - start
    data = resp.json()
    if resp.status_code != 200:
        print(model, "ERROR", resp.status_code, data)
        continue
    print("\n=== " + model + " ===")
    print(data["choices"][0]["message"]["content"])
    print(f"time: {seconds:.1f} seconds | text used: {data['usage']['total_tokens']}")

What does it cost?

Pay for what you use

Like phone airtime. You pay for the amount of text the AI reads and writes. Small per question, but it adds up.

Some models are free

Free models exist, with limits such as slower speed or a daily cap.

One account, many AIs

OpenRouter lets you try many models with one account and one key.

Prices change often, so always check the price shown on the model's page before using it.

If something goes wrong

Errors are normal. They are the computer's way of telling you what to fix.

What you seeWhat it usually meansWhat to do
Error 401The key is wrong or missingCopy the key again, with no extra spaces
Error 402The account has no credit for that modelChoose a free model instead
Error 429Too many requests too quicklyWait a minute, or try a different model
A JSON errorA typo such as a missing quote or an extra commaUse the JSON checker above

Quick quiz

Click an answer. You will see right away if it was correct, and why.

1. What does an LLM do at its core?

An LLM predicts likely text, again and again. That is why it can sound right and still be wrong.

2. ChatGPT is best described as…

LLM is the category, GPT is one family of models, and ChatGPT is the app you chat with.

3. In the restaurant comparison, what is the API key?

The key proves who you are and who should be billed, which is why you keep it secret.

4. Which of these is correct JSON?

JSON needs double quotes around labels and words, and no comma after the last item.

5. An AI tells you a date very confidently. What should you do?

The AI predicts text and cannot promise it is right. The same mistake can come back twice, so check with a reliable source.

Glossary

LLM (Large Language Model)
A program trained on a huge amount of text to predict what text comes next.
Model
A pattern the computer has learned. In this course, it means the AI itself.
GPT
One family of LLMs, made by OpenAI.
ChatGPT
An app with a chat window, built on GPT models.
Chat model
A model that answers directly. Fast and cheap.
Reasoning model
A model that works through steps before answering. Slower, costs more, better at multi-step problems.
Hallucination
When an AI states something false in a confident way.
API
The “waiter” that lets one program talk to another, such as your program talking to an AI.
Endpoint
The web address an API request is sent to.
GET and POST
GET asks for something. POST sends something, like an order.
API key
A secret password that identifies you. Keep it private.
Request and response
The request is what you send. The response is what comes back.
JSON
A tidy way of writing information as labels and values so computers can read it.
Token
A small chunk of text the AI reads and writes. Explained properly in Lesson 2.

Recap and what comes next

  1. An LLM guesses the next words, very well. It is not a search engine, and it is not a person.
  2. GPT is a model. ChatGPT is an app. LLM is the whole category.
  3. An API call is address + action + key + order, written as JSON.
