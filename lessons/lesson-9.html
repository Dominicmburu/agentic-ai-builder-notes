Data, expressions and webhooks

How data moves between boxes in n8n, and how other systems can start your workflow.

About 50 minutes to read Integration Download the slides

The big idea

Data in n8n is a list of items, each written as JSON. Expressions are how one box picks values out of data that came before. A webhook is a doorbell that lets other systems start your workflow.

By the end you can:

  • Read and write JSON data inside a workflow.
  • Use n8n expressions to pull values from earlier nodes.
  • Receive data through a webhook.

JSON in four steps

You met JSON in Lesson 1. Here it is again, built up one step at a time, using a spreadsheet as the comparison.

1. Key and value

One cell with its heading.

"name": "Wanjiru"

2. Object

One whole row, wrapped in curly braces.

{ "name": "Wanjiru", "city": "Nyeri" }

3. Array

A list of rows, in square brackets.

[ {"name": "Wanjiru"}, {"name": "Amina"} ]

4. Nesting

A value that is itself an object or list.

{ "name": "Wanjiru", "orders": [ {"item": "tea"} ] }

Reminder of the rules: keys need double quotes, and true and false are lowercase with no quotes.

Everyday comparison: a spreadsheet A spreadsheet of five customers is a list of five rows. n8n treats it the same way: five items. A node that processes items runs once for each one.

Expressions: picking values out of data

An expression goes inside double curly braces. It tells n8n: “put the value from over there into this field.”

You typeIt means
{{ $json.name }}The name field of the item that just arrived
{{ $json.orders[0].item }}The item inside the first order in the orders list. Counting starts at 0
{{ $('Google Sheets').item.json.email }}The email field from an earlier node, referred to by its name on the canvas
{{ JSON.stringify($json) }}Turn all the data into plain text

Why turn data into text? A language model reads text. If you want it to read a row of data, convert the data into text first with JSON.stringify.

In an n8n field you may need to switch the field to Expression mode (or just type two curly braces) before it understands the braces.

Reshaping data with Edit Fields

Data rarely arrives in the shape you need. The Edit Fields node lets you rename fields, add new ones and keep only what you want.

Everyday comparison: a form converter One office uses a form with “Full Name” and another uses “name”. Edit Fields is the clerk who copies the information from one form to the other.

For example, to build a single sentence for the AI from a row of a sheet, add a field called text and set it to:

Customer {{ $json.name }} from {{ $json.city }} ordered {{ $json.item }}.

APIs and webhooks

An API endpoint is an address that accepts requests. You used one in Lesson 1 when you sent a question to an AI. A webhook is the other way around: it is an address that your workflow gives out, so that other systems can call it when something happens.

Everyday comparison: the doorbell Your workflow is a house. A webhook is the doorbell. Anyone with the address can ring it, and when they do, the workflow wakes up and handles the visit.

GET

“Please give me some data.” No order slip needed.

POST

“Here is some data for you.” It carries a JSON body, like the order form in Lesson 1.

Set up a webhook

  1. Add a Webhook node and set the method to POST. Give it a path.
  2. The node shows two addresses. The test URL only works while you press “Listen for test event”. The production URL works when the workflow is active.
  3. Send a test request from a terminal, or a tool like Postman:
curl -X POST "YOUR_TEST_URL_HERE" \
  -H "Content-Type: application/json" \
  -d '{"name": "Wanjiru", "message": "Hello"}'

The data you sent appears under body, so the name is read with {{ $json.body.name }}.

A webhook is an open door Anyone who finds the address can call it. For real use, add a secret check, for example a required header, so only trusted senders get in.

Your exercise

Pull rows from a Google Sheet, reshape the fields with Edit Fields, and send each row to an agent that writes a one-line summary.

  1. Make a Google Sheet with a header row and five rows, for example name, city, item and quantity.
  2. Add a Google Sheets node to get the rows. Check that you see five items in the output.
  3. Add an Edit Fields node that creates one field called text, a sentence built from the columns.
  4. Add an AI Agent whose prompt is the text field and whose instruction is “Write a one-line summary.”
  5. Run it. Open the agent's execution and confirm it ran five times, once per row.

If something goes wrong

What you seeWhat it usually means
undefined in a fieldSpelling or capital letters differ from the real field name. Look at the previous node's output and copy the name.
The expression text shows as plain wordsThe field is not in Expression mode.
Only one row was processedAn earlier node returned one item, or you used the first item only. Check the item count after each node.
The webhook does nothingYou used the test URL without listening, or the production URL on an inactive workflow.
{{ $json.name }} is empty for a webhookWebhook data sits under body: use $json.body.name.

Quick quiz

Click an answer. You will see right away if it was correct, and why.

1. What does {{ $json.name }} do?

$json is the current item's data, and .name picks one field.

2. How can you read a value from an earlier node?

Expressions can reach back to earlier nodes by name.

3. What is a webhook?

It is the doorbell of your workflow.

4. Which method sends data with a JSON body?

GET fetches. POST sends.

5. Why use JSON.stringify before giving data to a model?

Stringify converts structured data into a piece of text.

Glossary

Item
One piece of data passing through n8n, usually one row of a sheet.
Key and value
A label with its data, like a spreadsheet heading and a cell.
Object
A group of key-value pairs wrapped in curly braces. One row.
Array
A list written in square brackets. Counting starts at 0.
Nesting
Putting objects or lists inside other objects.
$json
In an n8n expression, the data of the current item.
JSON.stringify
Turns structured data into plain text that a model can read.
Edit Fields
An n8n node that renames, adds or removes fields so data fits the next step.
Webhook
An address your workflow gives out. When another system calls it, the workflow starts.
Endpoint
An address that accepts requests.
GET
A request that asks for data.
POST
A request that sends data, usually with a JSON body.

Recap and what comes next

  1. n8n data is a list of items. Each item is JSON: keys and values, objects, arrays and nesting.
  2. Expressions in double curly braces pull values from the current item or from earlier nodes.
  3. Edit Fields reshapes data. JSON.stringify turns data into text a model can read.
  4. A webhook is a doorbell that starts a workflow. Use GET to fetch and POST to send.
