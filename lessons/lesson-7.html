Agentic AI in n8n: tools, memory and the human trap

Give your agent tools and memory, and avoid treating it like a person.

About 45 minutes to read Core Download the slides

The big idea

An agent is an AI that runs tools in a loop to reach a goal. That is the working definition for the rest of the course.

By the end you can:

  • Give an n8n agent tools and a memory node.
  • Spot the trap of treating the AI as if it were a person.
  • Choose between a chat model and a reasoning model for a task.

The five tricks behind every agent

There is no magic in an agent. Five simple tricks, all things you already know, combine to make one:

TrickWhat it meansWhere you met it
1. Illusion of memoryThe app re-sends the conversation each timeLesson 4
2. ChainingThe output of one AI step becomes the input of the nextLike passing a note along a line
3. ToolsThe AI asks, your app actsLesson 4
4. The loopDecide, act, observe, repeat until doneLesson 4
5. Thinking (reasoning)The AI works through steps before answeringLesson 1, reasoning models
Everyday comparison: a new assistant at work Picture an assistant with a notebook (memory), a phone and a calculator (tools), a checklist (the loop), and the habit of thinking before answering. None of those is clever alone. Together they get things done.

Adding memory and tools in n8n

On the AI Agent node you will see slots at the bottom. Each has a + button.

Memory

Add a Simple Memory node. It keeps the last few messages and re-sends them each turn, which is the illusion of memory from Lesson 4. It has a setting for how many past messages to keep. That is your trim strategy.

Tools

Add a tool such as Calculator or Wikipedia. The agent now sees the tool's name and description and can ask for it, exactly like the loop in Lesson 4.

The tool description is a prompt too The agent chooses tools by reading their names and descriptions. A clear name and a plain description of when to use it is what makes an agent reliable. If the agent ignores a tool, improve the description first.

Add a line to your system message to guide it, for example:

Add to the system messageFor ANY arithmetic, always use the Calculator tool. For questions about public facts, use the Wikipedia tool. Do not use a tool when you can answer directly.

The human trap

It is natural to talk to an AI as if it were a person. It writes like one, so we assume it thinks like one. That assumption leads to two kinds of failure.

The trap Treating the model as a person makes you write vague prompts (“you know what I mean”) and build fragile designs (assuming it will just figure it out).
If you treat it like a personTreat it like a program that follows text
“You know what I mean.”State the task, rules and format in writing
“It will remember from last time.”Add a memory node, or include what it needs
“It will know to double-check.”Add a calculator tool, a rule, and a test
“It tried hard, so it is probably right.”Check output against a test set

Lesson 19 returns to this trap with a security angle.

Chat model or reasoning model?

Chat model

Quick, cheaper. Good for summaries, rewriting, classifying and most everyday agent work.

Reasoning model

Slower, costs more. Good for multi-step problems that need planning.

There is a twist. Inside an agent, a plain chat model sometimes behaves better than a reasoning model, because the agent loop already gives it room to work step by step. Do not assume the bigger model is better. Test both on the same questions.

Your exercise

Add a memory node and one tool to your Lesson 6 agent, then test two things:

  1. A question that needs the tool. For example, “What is 17.5% of 2,480?” Open the execution and confirm the Calculator was called.
  2. A follow-up that needs the memory. Say “My name is Amina”, ask something else, then ask “What is my name?”
  3. A control test. Remove the memory node and repeat step 2. Note what changes.

If something goes wrong

What you seeWhat it usually means
The agent does the sum itself and gets it wrongIt did not use the tool. Make the rule firmer and check the tool's name and description.
It never remembersThe memory node is not connected, or the chat session changed. Test in one continuous chat.
It uses a tool for everythingAdd “do not use a tool when you can answer directly”.
The model does not support toolsPick a model that lists tool support.

Quick quiz

Click an answer. You will see right away if it was correct, and why.

1. What is the working definition of an agent in this course?

Tools plus a loop plus a goal. That is what makes it an agent.

2. Which of these is one of the five tricks behind agents?

The five are illusion of memory, chaining, tools, the loop, and thinking or reasoning.

3. What is the human trap?

The AI predicts text. Writing explicit instructions and testing beats hoping it understands.

4. What does a memory node do?

It is the notebook from Lesson 4, handled for you.

5. Your agent keeps ignoring a tool. What should you check first?

Agents choose tools by reading their descriptions, so clear descriptions are the first fix.

Glossary

Agent
An AI model that runs tools in a loop to reach a goal.
Chaining
Passing the output of one AI step to the next as its input.
Simple Memory
An n8n node that stores recent messages and re-sends them, giving a chat the illusion of memory.
Anthropomorphizing
Treating the AI as if it were a person. Leads to vague prompts and fragile designs.
Reasoning model
A model that works through steps before answering. Slower and costlier, good for multi-step problems.
Chat model
A model that answers directly. Faster and cheaper.

Recap and what comes next

  1. An agent is an LLM that runs tools in a loop to reach a goal.
  2. Five tricks make an agent: illusion of memory, chaining, tools, the loop, and thinking.
  3. Tool names and descriptions are prompts. Write them clearly.
  4. Do not treat the AI like a person. Write explicit instructions and test them.
