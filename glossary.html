Reference

A to Z glossary

Every term from every lesson, in plain words. Click the lesson tag to see it explained.

A

Account Executive Lesson 20
The person who talks to interested customers. Here, the agent that prepares meeting briefings.
Action Lesson 6
A node that does something after the trigger, such as call an AI or send an email.
Active (or Publish) Lesson 6
Switching a workflow on so it runs by itself in real use.
Agent Lesson 4
An AI that runs tools in a loop to reach a goal.
Agentic RAG Lesson 13
RAG where the agent chooses when and how often to search.
Agent loop Lesson 4
The repeating cycle of decide, act with a tool, observe the result, and continue until the goal is met.
Agents platform Lesson 11
ElevenLabs' tools for running a live voice conversation with an AI.
Anthropomorphizing Lesson 7
Treating the AI as if it were a person. Leads to vague prompts and fragile designs.
API Lesson 1
The “waiter” that lets one program talk to another, such as your program talking to an AI.
API key Lesson 1
A secret password that identifies you. Keep it private.
Array Lesson 9
A list written in square brackets. Counting starts at 0.
Authentication Lesson 8
Proving who you are and what you are allowed to do.

B

BDM Lesson 20
Business development manager. Here, the manager agent that directs the others.

C

Call n8n Workflow Tool Lesson 19
The n8n node that lets an agent call another workflow as a tool.
Capstone Lesson 20
The final project that combines everything in the course.
Chaining Lesson 7
Passing the output of one AI step to the next as its input.
ChatGPT Lesson 1
An app with a chat window, built on GPT models.
Chat model Lesson 1
A model that answers directly. Fast and cheap.
Chunk Lesson 13
A short passage cut from a larger document, searched and retrieved on its own.
Code node Lesson 10
An n8n node where you write a small piece of code to process data.
Connection Lesson 6
The line between two nodes that passes data along.
Container Lesson 16
A sealed box holding a program and everything it needs.
Context engineering Lesson 3
Choosing everything the AI sees in a call, not only the wording of the instructions.
Context window Lesson 2
The maximum number of tokens an AI can handle in one call, input and output together.
Conversation history Lesson 4
The list of earlier messages that the app re-sends on each turn.
Creative platform Lesson 11
ElevenLabs' tools for generating audio, such as reading text aloud in a chosen voice.
Credential Lesson 6
A safe place inside n8n where a key or login is stored.

D

Dimensions Lesson 14
The length of an embedding, for example 1536 numbers.
Docker Lesson 16
A tool that runs programs in sealed boxes called containers.
Draft Lesson 8
An email saved but not sent.
Drift Lesson 10
The difference between an asset's weight and its target, in percentage points.

E

Edit Fields Lesson 9
An n8n node that renames, adds or removes fields so data fits the next step.
ElevenLabs Lesson 11
A company that makes realistic AI audio. It offers a creative platform and an agents platform.
Embedding Lesson 13
A list of numbers that stands for the meaning of a piece of text.
Endpoint Lesson 1
The web address an API request is sent to.
Error branch Lesson 17
A path the workflow takes when a node fails, instead of stopping.
Error Trigger Lesson 17
The start node of a workflow that runs when another workflow fails.
Evaluation Lesson 20
Measuring how well the system works with a fixed set of tests.
Execute Workflow Lesson 17
The n8n node that runs another workflow.
Execution Lesson 6
One run of a workflow, saved so you can inspect it.
Expected result Lesson 5
What you decided, before the test, would count as a correct answer.
Expression Lesson 8
A small piece of code in double curly braces that pulls data into a field. Explained in Lesson 9.

F

Failure report Lesson 5
A short write-up of the worst test failures, their causes and the fixes.
Few-shot examples Lesson 3
A few worked input-and-answer pairs placed in the prompt to show the AI what you want.
Firecrawl Lesson 20
A service that reads web pages and returns their content in a form an AI can use.
First message Lesson 11
The greeting a voice agent says when a conversation begins.

G

GET Lesson 9
A request that asks for data.
GET and POST Lesson 1
GET asks for something. POST sends something, like an order.
GPT Lesson 1
One family of LLMs, made by OpenAI.
Grounding Lesson 13
Making the AI answer only from the retrieved information.
Grounding prompt Lesson 15
Instructions telling the agent to answer only from retrieved information.

H

Hallucination Lesson 1
When an AI states something false in a confident way.
Host Lesson 18
The AI application that wants to use tools.
HTTP Request node Lesson 12
An n8n node that calls any web API, including ElevenLabs.
Human in the loop Lesson 19
A person approves risky actions before they happen.
Hunter.io Lesson 20
A service that finds work email addresses for a company.

I

ICP Lesson 20
Ideal Customer Profile. A description of the kind of company you most want to sell to.
Ingestion Lesson 13
The one-off preparation phase: cut documents into chunks, embed them, store them.
Input tokens Lesson 2
The tokens you send to the AI, including your instructions and earlier conversation.
In scope Lesson 15
A question the agent should be able to answer from its data.
Integration Lesson 8
A connection between n8n and another service, such as Gmail or Google Drive.
Item Lesson 9
One piece of data passing through n8n, usually one row of a sheet.

J

JSON Lesson 1
A tidy way of writing information as labels and values so computers can read it.
$json Lesson 9
In an n8n expression, the data of the current item.
JSON.stringify Lesson 9
Turns structured data into plain text that a model can read.

K

Key and value Lesson 9
A label with its data, like a spreadsheet heading and a cell.

L

Label Lesson 3
The correct answer for an item in a test set.
Latency Lesson 11
The delay between you finishing speaking and the agent starting to answer.
Least privilege Lesson 18
Giving only the permissions that the job needs.
Lethal trifecta Lesson 19
Private data, untrusted content and a way to send data out, together in one agent.
LLM (Large Language Model) Lesson 1
A program trained on a huge amount of text to predict what text comes next.
localhost Lesson 16
The address that means 'this computer'.
Local model Lesson 16
An AI model running on your own machine.

M

Manager agent Lesson 19
An agent that delegates parts of a request to sub-agents.
MCP Lesson 18
Model Context Protocol. A standard way for AI apps to use outside tools.
MCP client Lesson 18
The part inside the host that speaks MCP and connects to servers.
MCP Client Tool Lesson 18
The n8n node that lets an agent use a server's tools.
MCP server Lesson 18
A program that offers tools in the MCP standard.
MCP Server Trigger Lesson 18
The n8n node that offers your workflows as tools to other MCP clients.
Metadata Lesson 14
Extra labels attached to a chunk, such as product name and category.
Model Lesson 1
A pattern the computer has learned. In this course, it means the AI itself.

N

n8n Lesson 6
A tool for building automations by connecting boxes (nodes) on a canvas.
Nesting Lesson 9
Putting objects or lists inside other objects.
Node Lesson 6
One step in a workflow. Either a trigger or an action.
npx Lesson 16
A Node.js command that downloads and runs a tool in one step.

O

OAuth2 Lesson 8
The 'Sign in with Google' style of login. You approve limited permissions without sharing your password.
Object Lesson 9
A group of key-value pairs wrapped in curly braces. One row.
Ollama Lesson 16
A free program that downloads and runs open AI models on your computer.
Orchestration Lesson 12
Deciding which part runs, and in what order. Who is in charge.
Out of scope Lesson 15
A question the agent should politely decline.
Output tokens Lesson 2
The tokens the AI writes back.
Over-using tools Lesson 5
Calling a tool when a direct answer would do.

P

Pass rate Lesson 5
The share of test prompts the assistant got right, for example 16 of 20 is 80%.
Pattern A Lesson 12
n8n orchestration: the whole workflow runs in n8n, which calls ElevenLabs for speech.
Pattern B Lesson 12
ElevenLabs orchestration: the voice agent runs the conversation and calls an n8n workflow as a tool.
pgvector Lesson 14
An add-on that lets PostgreSQL store and search embeddings.
Portfolio Lesson 10
A collection of investments held together. In this project, practice data only.
POST Lesson 9
A request that sends data, usually with a JSON body.
PostgreSQL Lesson 14
A widely used database. Supabase is built on it.
Pre-configured OAuth2 Lesson 8
OAuth2 where n8n has already done the hard setup. You just click sign in.
Production URL Lesson 12
The webhook address that works while the workflow is active. Use it for live agents.
Prompt Lesson 3
The instructions and data you send to an AI.
Prompt injection Lesson 19
Hidden instructions inside content that an agent reads, which try to steer it.
Prospecting Lesson 20
Finding companies and contacts who might want your product.

R

RAG Lesson 13
Retrieval-Augmented Generation. Look up relevant text first, then answer from it.
Rate limit (429) Lesson 17
A service telling you that you are sending too many requests.
Reasoning model Lesson 1
A model that works through steps before answering. Slower, costs more, better at multi-step problems.
Rebalancing Lesson 10
Buying and selling to bring weights back to their targets.
Regression Lesson 15
A fix that breaks something that used to work. Re-run the whole test after every change.
Request and response Lesson 1
The request is what you send. The response is what comes back.
Request body Lesson 17
The data sent along with a POST request, usually JSON.
Respond to Webhook Lesson 12
An n8n node that sends an answer back to whoever called the webhook.
Retry On Fail Lesson 17
A node setting that tries the step again after an error.
RevOps Lesson 20
Revenue operations. Here, the agent that records and checks sales data.

S

Schedule trigger Lesson 10
An n8n node that starts a workflow at set times, such as once a day.
SDR Lesson 20
Sales development representative. Here, the agent that drafts outreach.
Self-hosted Lesson 16
Running software on a computer you control instead of the provider's servers.
Service key Lesson 14
A master key for your Supabase project. Never share it.
Similarity search Lesson 13
Finding the stored chunks whose embeddings are closest to the question's.
Simple Memory Lesson 7
An n8n node that stores recent messages and re-sends them, giving a chat the illusion of memory.
Speech to text Lesson 11
Turning spoken audio into written words. The agent's ears.
SQL Lesson 14
The language used to talk to a database.
SSE Lesson 18
An older web transport, now deprecated.
Stateless Lesson 4
Keeping nothing between calls. An AI model is stateless; the app supplies the memory.
Status code Lesson 17
A number in the reply that says how it went: 200 worked, 4xx your mistake, 5xx their problem.
stdio Lesson 18
Local transport: the host starts the server on the same computer.
Streamable HTTP Lesson 18
The current recommended transport for remote servers.
Structured output Lesson 3
A reply in a fixed format, such as JSON, that a program can read.
Sub-agent Lesson 19
A specialist agent that a manager agent calls to do part of a job.
Sub-workflow Lesson 17
A workflow called by another workflow, like a reusable recipe card.
Summarise Lesson 4
Replace old messages with a short recap to save space.
Supabase Lesson 14
An online database service built on PostgreSQL, with a free tier.
System prompt Lesson 3
The standing role and rules for the AI, set once. Like a job description.

T

Target weight Lesson 10
The share you planned for an asset.
Temperature Lesson 2
A setting that controls how predictable or varied the AI's picks are. Low is predictable, high is varied.
Template Lesson 6
A ready-made workflow you can copy and change.
Test set Lesson 3
A fixed list of example inputs with the correct answers, used to score prompts fairly.
Test URL Lesson 12
The webhook address that only works while you are listening for a test event in n8n.
Text to speech Lesson 11
Turning written words into spoken audio. The agent's mouth.
Threshold Lesson 10
The drift size above which an asset is flagged.
Token Lesson 1
A small chunk of text the AI reads and writes. Explained properly in Lesson 2.
Tokenizer Lesson 2
The tool that splits text into tokens. Each model family has its own.
Tool Lesson 4
A function in your app that the AI can ask for, such as a calculator or a search.
Tool call Lesson 4
A structured request from the AI saying which tool to run and with what inputs.
Top-k Lesson 14
How many of the closest chunks the search returns.
Transport Lesson 18
The way client and server talk: stdio, Streamable HTTP or SSE.
Trigger Lesson 6
A node that starts a workflow, such as a chat message or a schedule.
Tunnel (ngrok) Lesson 16
A service that gives a program on your computer a temporary public web address.
Turn-taking Lesson 11
Knowing when one speaker has finished so the other can start, including interruptions.

U

User prompt Lesson 3
The specific request or data for this call. Like today's task.

V

Vector store Lesson 13
A database that holds embeddings and can search them by closeness.
Volume Lesson 16
A place outside the container where data is saved so it survives restarts.

W

Webhook Lesson 9
An address your workflow gives out. When another system calls it, the workflow starts.
Webhook tool Lesson 12
A tool for a voice agent that calls a webhook address to trigger a workflow.
WEBHOOK_URL Lesson 16
An n8n setting that tells it which public address to show for webhooks.
Weight Lesson 10
An asset's value as a share of the whole portfolio's value.
Workflow Lesson 6
A set of connected nodes that does a whole job.
Agentic AI Builder notes. Button names and menus in online tools change from time to time; if you see something different, look for the same idea.
